# BookAI

Kirjatehtävien työtila.

https://latemake.github.io/bookai/

Tämä käyttöliittymäversio tukee kirjan kuvien ja PDF-tiedostojen lisäämistä, tehtäviä, omia vastauksia ja sivuviitteitä. Tiedot tallentuvat nykyisen selaimen IndexedDB-tallennukseen. Selaimen tietojen tyhjentäminen poistaa tallennukset.

AI-yhteys ja tekstintunnistus eivät vielä ole käytössä. HEIC-esikatselu riippuu selaimen tuesta.

GitHub Pages julkaisee main-haaran juuren. Sovellus ei tarvitse rakennusvaihetta.
